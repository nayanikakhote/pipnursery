# 🌒 Pip's Midnight Nursery

Pip's Midnight Nursery is an interactive portfolio featuring Pip, a tiny skull baby with a very important job: Junior Dream Engineer.

Welcome to Pip's little corner of the internet, where bedtime comes with its own operating system, lullabies have their own programs, and even the nightlights have a personality. 🪔 Boot up DreamOS 98, poke around the nursery, deliver a few dreams, and see what happens when a curious little skull baby gets his hands on a computer.

There's music to make 🎼, toys to play with 🪇, a bedtime story to uncover 📖, and wishes waiting to be left behind. If you're the sort who clicks on absolutely everything, you're in luck. Pip has a few secrets tucked away for visitors who refuse to go to bed on time. 🗝️

Built as a playful, interactive portfolio, Pip's Midnight Nursery brings together a nostalgic desktop experience, small interactive projects, character-driven storytelling, and a handful of surprises. It's part portfolio, part nursery, and part very tiny dream factory. 🧸

## Features
- DreamOS 98: A Windows 98-inspired desktop environment with interactive windows, a taskbar, and a Start menu.
- Lullaby.exe: An interactive music sequencer for composing little lullabies. 🎼
- Nightlights: Character-themed lamps with interactive elements. 🪔
- Dream Routes: A rooftop map featuring dream delivery routes. 🌙
- Rattle & Blocks: Interactive nursery toys and mini-games. 🪇
- Bedtime Story: An interactive storybook featuring Boo and the Borrowed Moon. 📖
- Growth Chart: A visual record of Pip's progress. 📏
- PipChat.exe: A character chat for stories, songs, and hints.
- Dream Wishes: A guestbook where visitors can leave their wishes. ✉️
- My Story: A five-chapter exploration of Pip's backstory.
- Hidden Easter Eggs: Little surprises for visitors who explore beyond the obvious. 🗝️

## Tech Stack

- React: UI development
- TypeScript: Type safety
- Vite: Development server and build tooling
- Zustand: State management
- Framer Motion: Animations and transitions
- Web Audio API: Audio interactions
- Supabase: Optional backend functionality

## Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/?utm_source=chatgpt.com)
- npm, included with Node.js

### Installation

1. Clone the repository:
   ```
   git clone https://github.com/nayanikakhote/pipnursery.git
   ```
2. Navigate to the project directory:
   ```
   cd pipnursery
   ```
3. Install the dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```
5. Open the local URL displayed in your terminal to explore the nursery.

## Production Build

Create an optimized production build:

```
npm run build
```

Preview the production build locally:

```
npm run preview
```

## Project Structure

The project is organized around an interactive desktop experience, with individual components and features powering the nursery, mini-games, music interactions, storybook, and other experiences.
